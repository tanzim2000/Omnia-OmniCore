## 6. If you work for someone

If your employer, school or client could own what you create (many job
contracts say so), make sure they agree to you contributing under this
agreement, or get them to agree to it themselves. If an organisation
agrees, "You" means the organisation, and it covers the Contributions its
people send for it.

## 7. Other people's work

If you send something that isn't entirely yours (copied code, a library,
an image), say so when you send it: where it comes from, who made it, and
its licence. Only send it if that licence allows it to be used in
OmniCore.

have to support them. The Maintainer doesn't have to use them.

## 9. If something changes

If you learn that any promise in section 5 isn't true any more, tell the
Maintainer as soon as you can.

## 10. How to agree

On your first pull request, post this comment:

> I have read the Contributor Licence Agreement (CLA.md) and I agree to it.

That covers that pull request and every Contribution you send after it.
If OmniCore later uses a tool to collect agreements (such as CLA
Assistant), you can agree through that instead.
